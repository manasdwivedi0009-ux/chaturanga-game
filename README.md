# चतुरंग · Chaturanga Game

Ancient Indian Chess game — play directly in the browser!

## 🎮 Play Now
👉 [Click here to play Chaturanga](https://manasdwivedi0009-ux.github.io/chaturanga-game/)

## 📜 Rules
- King (राजा) - 1 step any direction
- Chariot (रथ) - straight line
- Elephant (गज) - 2 steps diagonally
- Horse (अश्व) - L-shape
- Minister (मंत्री) - 1 step diagonally
- Pawn (पदाति) - 1 step forward, capture diagonal
